# Como navegar neste perfil

Este repositório funciona como uma vitrine e um ponto de partida para aprender a criar bots. As áreas públicas foram organizadas para que cada visitante saiba onde encontrar uma tarefa, um fluxo automatizado, um projeto ou uma orientação de segurança.

## Issues e o relatório de problemas

A página de Issues é o relatório de problemas e sugestões. Quando aparece “Nenhuma sessão corresponde aos seus filtros” ou “No results”, isso significa que a busca atual não encontrou issues abertas; não significa que o GitHub esteja quebrado. Use “New issue” para abrir um relato, remova filtros como `is:issue state:open` quando necessário e verifique também a aba de issues fechadas.

## Actions

A área Actions mostra as verificações automatizadas do repositório. Workflows devem validar o projeto sem armazenar tokens no código. Quando não há workflows, a área pode aparecer vazia; isso é um estado inicial normal, não um erro.

## Projects

A área Projects organiza o trabalho em colunas simples: Ideias, Próximo, Em andamento, Em revisão e Concluído. Cada cartão deve apontar para uma issue ou tarefa real. O objetivo é tornar o progresso legível, sem criar atividades fictícias.

## Security and quality

A área Security and quality concentra alertas de dependências, secret scanning e recomendações do GitHub quando essas funções estão disponíveis. A política completa está em [SECURITY.md](SECURITY.md).
