# 🎨 Emojis e Figurinhas para Comandos



Catálogo visual para respostas do bot. Os emojis abaixo funcionam como marcadores de intenção; as imagens de figurinha devem ser mídias autorizadas e convertidas para WebP.



## 🤖 Identidade do bot



| Emoji | Uso sugerido | Comando |

|---|---|---|

| 🤖 | Bot online | `/ping` |

| 🧠 | Inteligência artificial | `/ia` |

| ⚙️ | Configurações | `/config` |

| 🧩 | Criar integração | `/integrar` |

| 🚀 | Iniciar fluxo | `/iniciar` |



## 🎫 Atendimento e tickets



| Emoji | Uso sugerido | Comando |

|---|---|---|

| 🎫 | Abrir ticket | `/ticket abrir` |

| 📝 | Registrar assunto | `/ticket assunto` |

| 🔎 | Consultar ticket | `/ticket status` |

| ✅ | Ticket resolvido | `/ticket fechar` |

| 🧑💻 | Atendimento humano | `/atendente` |

| ⏳ | Em andamento | `/ticket aguardar` |



## 🎨 Figurinhas



| Emoji | Ideia de figurinha | Comando |

|---|---|---|

| 😂 | Risada | `/sticker rir` |

| 🔥 | Destaque | `/sticker fogo` |

| 👀 | Atenção | `/sticker olhar` |

| 🙌 | Comemoração | `/sticker comemorar` |

| 💡 | Ideia | `/sticker ideia` |

| 🫡 | Confirmação | `/sticker ok` |

| 🛠️ | Construção | `/sticker build` |

| 🎉 | Sucesso | `/sticker sucesso` |



## 🛡️ Regras de uso



- Use apenas imagens próprias, licenciadas ou autorizadas.
- 
- Não envie mensagens repetitivas sem consentimento.
- 
- Não use emojis ou figurinhas para ocultar spam, fraude ou assédio.
- 
- Mantenha arquivos de mídia pequenos e em formato compatível.
- 
- Consulte `figurinhas/` para conversão e envio de arquivos WebP.
- 
- Este catálogo é uma referência de design; ele não afirma que cada comando já está implementado.
- 


## 🧪 Exemplo de resposta



```txt

🤖 Bot online!

🎫 Para abrir atendimento, use /ticket abrir <assunto>

🎨 Para uma figurinha, responda a uma imagem autorizada com /sticker

✅ Use /ajuda para ver os comandos disponíveis

```
